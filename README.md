# 🎓 Student Management App

A simple and user-friendly **Student Management App** developed using Flutter and Dart. This application helps users manage student records by adding, viewing, and deleting student details through a clean and easy-to-use interface.

## ✨ Features

- **Add Students:** Add new student records.
- **View Students:** View the available student details.
- **Delete Students:** Remove student records when they are no longer needed.
- **User-Friendly Interface:** Simple and clean Flutter UI.
- **Cross-Platform Development:** Built with Flutter.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Flutter | Mobile application development |
| Dart | Programming language |
| SharedPreferences | Local key-value storage dependency |
| Material Design | User interface |

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/fathimanadin824-glitch/student-management-app.git
```

### 2. Open the Project

```bash
cd student-management-app
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```

The main objective of this project is to develop a simple student management application using Flutter. It helps users organize student records and provides practical experience in Flutter UI development and application functionality.
